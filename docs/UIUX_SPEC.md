# VC Radar / Social Radar UI/UX 设计规范

> 版本：V3.0（Social Product Radar 产品优先规范 + 归档兼容）  
> 适用范围：`vcradar/site_assets/`（`tokens.css`、`components.css`、`style.css`、`index.html`、`icons.svg`、`app.js`）、`functions/media/[[key]].js` 及 `vcradar/site.py` 静态站点产物。

---

## 1. 产品定位与核心设计原则

项目聚焦**以具体社交/社群产品为主角的早期产品发现与多方交叉拆解（Social Radar）**，同时保留底层早期融资归档视图。界面表现层严格遵循以下五项原则：

1. **产品本位（Product-First Protagonist）**  
   每张卡片与详情浮层以具体的社交/社群 App 或 Web 产品为第一视觉主角（产品图标、一句大白话切入点、真实界面/评测实拍配图、6 维度拆解），所属公司、融资轮次/金额、投资方与多国榜单排名作为背书元数据紧密关联。
2. **克制留白与零废话文案（UI & Copy Discipline）**  
   不添加多余的副标题、介绍横幅、营销导语或页脚口号；直接依靠清晰的导航分段、状态胶囊、机制标签与卡片信息层级自解释。
3. **纯矢量图标与纸感编辑风（SVG-Only & Calm Editorial Paper）**  
   UI 控件严禁使用 Emoji 充当功能图标，全部采用 `icons.svg` 内联 SVG 矢量符号；底色沿用暖纸底（`#F6F6F3`）与纯白承载面（`#FFFFFF`），支持浅色、深色与跟随系统无闪烁切换。
4. **0ms 预生成秒开与多方交叉透明**  
   所有准入产品的 6 维度拆解、多方交叉比对结论与 R2 托管配图均在离线构建期预生成内联至 `data.json`，前端点击卡片零网络等待直出详情，彻底消除「解读生成中」等待态。
5. **零滚动穿透（Zero Scroll Bleed-Through）**  
   产品详情浮层开启时强制执行 `body` 固定位锁死（`position: fixed; top: -scrollY` + 滚动条宽度补偿），浮层头部黏性置顶（`position: sticky`），正文独立滚动容器启用 `overscroll-behavior: contain`，遮罩层拦截外部 `wheel` 与 `touchmove` 事件，彻底杜绝滚动穿透到底层列表。

## 2. 信息架构与路由契约

站点为纯静态单页应用（Hash 路由，媒体资源经同源 Cloudflare Pages Function `/media/<sha256>.<ext>` 从 R2 `vc-radar-media` 直出）：

| 路由 | 视图名称 | 核心信息结构与交互契约 |
| :--- | :--- | :--- |
| 默认空 Hash / `#radar` | **Social Radar 社交产品主视图**（当库内含已准入社交产品时为默认首页） | 顶栏提供三个一级视图切换：**`全部`**、**`早期融资`**、**`冲榜新品`**；筛选栏左侧为社交机制胶囊（`熟人/密友`、`陌生人/破冰`、`兴趣/品味社区`、`多人共创`、`校园/破冰`、`AI辅助连接`），右侧随一级视图联动切换（`早期融资` 下展示 `仅看已上线` / `含内测 / 未开放`；`冲榜新品` 下展示 `独立新锐` / `大厂独立新包`）。 |
| `#p/<slug>` | **社交产品 6 维度深度拆解浮层** | 在当前产品网格之上 0ms 打开详情模态框，展示产品头部、关联公司/融资/榜单信息条、R2 托管实拍图与商店截图画廊（支持点击灯箱放大）、多方交叉比对摘要卡、6 维度中文母语大白话拆解（首节固定为 **`产品形态与切入点`**）及可点击跳转的热门评测帖与报道参考列表。 |
| `#week` / `#list` / `#yc` / `#backfill` / `#c/<id>` | **底层早期融资归档与公司尽调视图** | 完整兼容历史期次归档、四维筛选抽屉与单公司尽调详情页。 |

## 3. 设计令牌系统（Design Tokens — `tokens.css`）

所有视觉原子统一收敛于 `vcradar/site_assets/tokens.css`，支持浅色、深色（`:root[data-theme="dark"]`）与系统偏好自适应，持久化于 `localStorage["vcr-theme"]`：

- **色彩语义**：`--c-paper`（全局底色）、`--c-surface` / `--c-surface-2` / `--c-sunken`（卡片与分段槽位）、`--c-ink` / `--c-ink-2` / `--c-muted`（三级文字对比度满足 WCAG AA+）、`--c-signal`（主信号青黛色）、`--c-social`（社交标签色）、`--c-ok`（已上架/多方印证色）、`--c-warn`（内测排队/口碑反差提示色）。
- **排印与等宽数字**：自托管 `Inter` WOFF2 + 中文系统无衬线字体栈；排名、金额与日期启用 `"tnum" 1, "lnum" 1`。
- **空间、圆角与阴影**：4px 基准栅格（`--s-1` .. `--s-16`），圆角 `--r-xs` .. `--r-pill`，阴影 `--elev-1`（卡片描边微影）与 `--elev-2`（详情模态浮层）。

## 4. 三层 CSS 架构与核心组件规范

表现层样式保持职责正交的三层结构（`tokens.css` → `components.css` → `style.css`），所有前端静态资产均严禁残留注释符号，且 `style.css` 严禁硬编码颜色字面量或新增 `--*:` 变量定义：

1. **顶栏与一级分段器（`.sr-bar` / `.sr-tabs`）**：黏性置顶，左侧紧凑品牌标识，中间/右侧为 `全部`、`早期融资`、`冲榜新品` 三段切换与单键 SVG 主题切换按钮，不展示任何副标题。
2. **联动筛选条（`.sr-filters`）**：左区机制胶囊单选过滤，右区在 `早期融资` 与 `冲榜新品` 下动态呈现上下文胶囊（带实时计数）。
3. **社交产品卡片（`.sr-card`）**：双列响应式网格（移动端单列，`>= 768px` 双列），含 52px 圆角产品图标、渠道角标、开发者与平台状态、一句大白话切入点（`.sr-hook`）、R2 缩略配图条（`.sr-media-strip`）、机制标签与底部公司/融资/热帖数量背书栏。
4. **零穿透详情模态框（`.sr-modal-backdrop` / `.sr-modal`）**：
   - `.sr-modal-head` 黏性置顶（`position: sticky; top: 0`），右侧配 `36×36px` SVG 关闭按钮与直达商店/官网动作按钮；
   - `#sr-detail-scroll` 独立承载纵向滚动（`overflow-y: auto; overscroll-behavior: contain`）；
   - 包含实拍/商店配图横向画廊（区分 `报道实拍图` 与 `App Store 截图` 角标，点击打开 `.sr-lightbox` 原图预览）、`多方交叉比对` 卡片、6 节编号大白话深度拆解与底部热帖/报道原文外链列表。

## 5. 键盘交互、无障碍与安全文案红线

1. **键盘与无障碍**：支持 `Escape` 优先关闭大图灯箱、再关闭产品详情浮层并恢复精确滚动位置；所有外链强制附带 `target="_blank" rel="noopener nofollow"`。
2. **媒体与发布洁净守卫**：站内图片统一通过 `/media/<sha256>.<ext>` 引用 Cloudflare R2 内容寻址对象；构建期强制经过 `site._validate_outputs()` 与用语洁净检查，拦截任何本机路径、密钥字样、占位链接或违规旧词。
