# VC Radar（早期创投监控）UI/UX 设计规范

> 版本：V2.0（Editorial VC Intelligence 规范）  
> 适用范围：`vcradar/site_assets/`（`tokens.css`、`components.css`、`style.css`、`index.html`、`icons.svg`、`app.js`）及 `vcradar/site.py` 静态站点产物。

---

## 1. 产品定位与核心设计原则

VC Radar 是面向早期风险投资人、投研团队与创业观察者的**高信噪比每周早期融资简报与尽调阅读器**（聚焦天使轮、种子轮、A 轮及 YC 最新批次）。界面表现层遵循以下四项核心原则：

1. **纸感编辑风（Calm Editorial Paper & Ink）**  
   摒弃后台监控仪表盘的繁杂框线与刺眼霓虹色，采用暖纸底色（`#F6F6F3`）搭配纯白内容承载层（`#FFFFFF`）与深墨正文（`#14171C`），主信号色采用沉稳的青黛色（`#0B6B66` / 深色模式 `#5CC2B8`），适合长时深度阅读。
2. **事实与不确定性透明分层**  
   - **已确认事实**：高对比度正文与等宽对齐数字（`tabular-nums lining-nums`），确保融资金额、日期纵向扫读对齐。  
   - **待确认 / 资料有出入**：以琥珀色语义强调（`--c-warn`）标注「轮次待确认」「金额待确认」「资料有出入」，并在详情页置顶展示推送冻结值与新来源原文引用的逐条对照，绝不静默覆盖或主观猜测。  
   - **未披露信息**：降级为次要灰度字重（`.is-none`），避免喧宾夺主。
3. **零运营噪音（Zero Operational Noise）**  
   页面只呈现对读者有决策价值的公司、融资与原文证据。严禁在界面任何位置暴露抓取状态页（`#sources`）、内部过滤计数器（「本周共 X 家」「已过滤 X 家」「共 X 条」）、内部状态词或提示词术语。
4. **移动优先与桌面高效兼顾（Mobile-First + Desktop Power-Reader）**  
   - **移动端（`< 1024px`）**：单栏流式阅读 + 顶部品牌栏 + 底部安全区双导航栏 + 底部模态筛选抽屉 + 吸顶横向章节导航条；所有可点击目标触控热区不小于 `44×44px`，在 `390px` 宽度下超长英文单词或长 URL 均严禁产生横向滚动溢出。  
   - **桌面端（`>= 1024px`）**：左侧常驻导航栏（`232px`）+ 居中阅读主栏（列表页最大内容宽 `880px`，详情页采用 `176px` 吸顶目录 + `760px` 正文双栏网格）+ 常驻平铺筛选卡片 + 键盘快捷操作。

## 2. 信息架构与路由契约

站点为纯静态单页应用（Hash 路由，零后端运行时依赖），包含以下视图：

| 路由 | 视图名称 | 核心信息结构与排序契约 |
| :--- | :--- | :--- |
| `#week` | **本周**（默认首页） | 按公司第一信源的**北京发布日期**降序分组（`MM-DD 周X`，非当年补齐 `YYYY-MM-DD 周X`；缺失发布日期归入末尾「发布时间未知」）。同日内按推送优先级排序（已披露金额 → 金额说法不一 → 金额未披露）。底部提供默认收起的「轮次待确认」与「不在收录范围」折叠抽屉。 |
| `#list` | **往期**（归档筛选） | 顶部提供四维结构化筛选器（`时间`、`标签`、`轮次`、`状态` + `此前漏掉` 标记），下方按日期分组展示卡片。遵循低认知负担原则，不放置自由文本搜索框或复杂排序下拉框；当存在非默认筛选条件时，提供激活数量提示与一键「重置」入口。 |
| `#backfill` | **补充未推送专页** | 自动激活往期视图的 `unsentOnly` 筛选态，顶部展示柔和提示条并提供「查看全部往期」一键切回链接。 |
| `#yc` | **YC 本批名录** | 展示当期 YC 批次收录公司的标准卡片列表。 |
| `#c/<id>` | **公司尽调详情页** | 按需异步加载 `./c/<id>.json`（内置请求去重缓存与失败重试按钮），严格按固定尽调阅读顺序呈现 10 个信息模块（见第 4.4 节）。 |
| 其他未知 Hash | 安全回退 | 包括历史遗留的 `#sources` 在内，任何未公开路由均安全回退渲染 `#week` 视图。 |

### 3.2 字体排印（Typography）

- **字体栈（`--font-sans`）**：自托管 `Inter`（400 / 500 / 600，仅打包 Latin 子集 WOFF2，零外部字体请求）搭配 `"PingFang SC", "HarmonyOS Sans SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif`。
- **数字特性（`--num-features`）**：全局金额、日期、编号统一启用 `"tnum" 1, "lnum" 1`（等宽齐线数字）。
- **字阶规范**：
  - `--t-display`：移动端 `600 26px/32px` → 桌面端 `600 32px/38px`（详情页公司主标题）
  - `--t-day`：移动端 `600 18px/26px` → 桌面端 `600 20px/28px`（日期分组标题）
  - `--t-name`：`600 17px/24px`（卡片公司名、详情二级分节标题）
  - `--t-amount`：`600 20px/26px`（详情关键字段核心金额）
  - `--t-read`：移动端 `400 16px/28px` → 桌面端 `400 16.5px/29px`（深度解读长文阅读字阶，单行最大宽度控制在 `38em` 以内）
  - `--t-body`：`400 15px/24px`（卡片产品描述与通用正文）
  - `--t-label`：`600 13px/20px`（导航、按钮、小节标签）
  - `--t-caption` / `--t-foot`：`400 13px/20px` / `400 12px/18px`（元数据、来源时间戳、辅助说明）

### 3.3 空间、圆角、阴影与动效

- **4px 基准空间栅格**：`--s-1`（`4px`）、`--s-2`（`8px`）、`--s-3`（`12px`）、`--s-4`（`16px`）、`--s-5`（`20px`）、`--s-6`（`24px`）、`--s-8`（`32px`）、`--s-10`（`40px`）、`--s-12`（`48px`）、`--s-16`（`64px`）。
- **圆角阶梯**：`--r-xs: 4px`（角标/徽章）、`--r-sm: 6px`（按钮/输入框）、`--r-md: 8px`（内嵌提示卡）、`--r-lg: 12px`（卡片列表容器/筛选卡/抽屉顶角）、`--r-pill: 999px`（筛选胶囊）。
- **阴影层级**：
  - `--elev-1`：细腻描边与极轻底影，用于承载 `.co-list`、`.fact-card` 与桌面 `.fpanel`，避免厚重弥散阴影。
  - `--elev-2`：用于移动端筛选抽屉（`.drawer`）与 Skip Link 浮层。
- **无障碍动效**：默认过渡时长 `--dur-fast: 120ms`、`--dur-base: 180ms`；在 `@media (prefers-reduced-motion: reduce)` 下自动归零所有位移与缩放动画，骨架屏停止闪烁。

## 4. 三层 CSS 架构与核心组件规范

表现层样式严格拆分为职责正交的三层，按固定顺序引入（`tokens.css` → `components.css` → `style.css`）：

1. **`tokens.css`**：唯一允许声明 `--*` 自定义属性与颜色字面量的文件。
2. **`components.css`**：定义自托管 `@font-face`、基础重置、应用壳及所有可复用 UI 组件样式，保持零死代码（不保留已废弃原型选择器）。
3. **`style.css`**：仅负责页面级响应式布局编排（如 `.fpanel.drawer` 在移动抽屉与桌面平铺卡之间的形态切换）及详情正文排版细节，**严禁出现任何 `--*:` 变量定义或 `#hex` / `rgb()` 颜色字面量**。

### 4.1 应用壳（App Shell）

- **Skip Link（`.skip`）**：默认屏幕外隐藏，键盘 `Tab` 聚焦时在左上角浮现「跳到正文」，回车焦点直达 `#main`。
- **移动端顶栏（`.appbar`）与底栏（`.tabbar`）**：`< 1024px` 显示。顶栏左侧为品牌标识，右侧为单键深浅色切换按钮（`44×44px`）；底栏固定于视口底部并适配 `env(safe-area-inset-bottom)`，提供「本周」「往期」两个一级入口。
- **桌面端侧栏（`.nav-side`）**：`>= 1024px` 显示，黏性定位于视口左侧（`height: 100vh`），顶部为品牌标识，中部为「本周」「往期」导航项，底部固定三态主题切换器（浅色 / 深色 / 跟随系统）。

### 4.2 公司融资卡片（`.co-card`）

每张卡片位于日期分组容器（`section.dgroup > .co-list`）内，左侧配 `40×40px` 首字彩色徽标（`.cmark`），主体（`.co-l`）严格按最多 6 行语义顺序呈现，无多余竖线伪元素干扰：

1. **`.co-r1`（身份与状态行）**：公司名称主链接（`h3.co-name > a.co-link`，覆盖整卡点击热区）+ 争议标记（`.mark`）+ 国家胶囊（`.co-country`，待确认时呈琥珀色 `.is-pend`）+ 领域标签组（`.co-tags > .tag`）+ 补录/待确认状态提示（`.mark.is-supp` / `.state-flag` / `.push-flag.next`）。
2. **`.co-prod`（产品定位行）**：以柔和前缀 `产品：` 引导首句核心产品定义，字色 `--c-ink` 突出可读性。
3. **`.co-fund`（本轮融资核心行）**：展示 `轮次 · 金额 · 领投方`。金额（`.co-amt-i`）采用加粗等宽数字；待确认金额（`.is-pend`）使用 `--c-warn`；未披露金额（`.is-none`）使用常规字重与 `--c-muted`。
4. **`.co-desc`（补充简介行，可选）**：当摘要包含第二句及以上时渲染 `简介：...`，字色 `--c-ink-2`，桌面端限制最佳阅读行宽 `72ch`。
5. **`.co-srcs`（来源行）**：列出所有报道信源及精简发布日期，外链层级置于整卡热区之上（`z-index: 1`），点击直接新标签页打开原文。
6. **`.co-more-l`（详情行动行）**：右侧/底部对齐的「详情 ›」链接，明确提示可进入深度尽调页。

### 4.3 往期筛选器（`#list` 工具栏与 `.fpanel.drawer`）

- **移动端（`< 1024px`）**：`.tb` 工具条展示「筛选」按钮（当存在激活筛选条件时显示数量角标及旁侧快捷「重置」按钮）。点击打开底部模态抽屉（`#filter-panel.is-open` + `#filter-scrim` 遮罩），锁定背景滚动并启用 `inert` 与 `Tab` 焦点环绕，`Escape` 或点击遮罩关闭并归还焦点。
- **桌面端（`>= 1024px`）**：隐藏 `.tb` 与抽屉头尾，`.fpanel.drawer` 静态平铺为圆角卡片，组名（`.lab`，宽 `40px`）居左，分段控制器（`.seg`）与胶囊组（`.chips`）同行排列；当存在非默认筛选条件时，末行展示快捷「重置」按钮。
- **指定某一期联动**：仅当用户点击「指定某一期」或当前处于 `date:YYYY-MM-DD` 态时，动态展开 `#issue` 期次下拉选择器。

### 4.4 公司尽调详情页（`#c/<id>`）

严格保持以下自上而下的阅读层级与无障碍语义：

1. **面包屑（`nav.crumb`）**：根据该公司是否属于本周列表，智能返回 `#week`（本周）或 `#list`（往期）。
2. **公司头部（`header.co-head`）**：大号首字徽标（`.cmark.lg`）+ 公司名 `h1`（若有官网则渲染安全外链）+ 标签与补录标记 + 独立行展示国家（绝不将「国家待确认」拼入 `h1`）。
3. **同名/身份提示（`.alert`，可选）**：仅在存在同名公司消歧说明时出现。
4. **资料有出入对照卡（`section.evidence`，可选）**：当深度抓取发现新来源与推送时冻结值不一致时置顶渲染，逐字段列出 `推送时写的：X；新来源写的：Y` 及带时间戳的原文 `<q>` 引言与来源链接。
5. **简介（`section > h2`「简介」）**：单段清晰概述并自动为已识别实体挂载安全外链。
6. **关键字段（`section > h2`「关键字段」+ `.fact-card > dl.facts`）**：响应式 2 列（移动）/ 3 列（桌面）信息网格，首格突出展示本轮金额（`.amt`）、原文轮次、领投与跟投；仅对已推送且在收录范围内的公司展示「推送日期」；底部紧随 `.facts-note` 查证批注。
7. **双栏深度解读区（`.detail.v2`）**：
   - **吸顶目录（`nav.toc`）**：移动端为吸顶横向滑动锚点栏，桌面端为左侧黏性竖向目录，配合 `IntersectionObserver` 自动高亮当前阅读章节（`01 产品是什么` … `08 风险与待确认`、`融资历史`、`全部来源`）。当解读处于「生成中 / 失败 / 未生成」状态时自动隐藏目录并展示 8 段骨架屏或状态说明卡。
   - **深度解读分节（`#deep-1` .. `#deep-8`）**：每节含编号徽标与语义图标；其中第 5 节「融资」固定使用 `dl.kv` 渲染当前事件四要素（本轮、领投、跟投、日期），其余章节采用「要点 + 原文 `<blockquote>` 引用 + 双行来源时间戳」结构。
8. **融资历史（`section#fund-hist > ol.ftl`）**：按日期倒序纵向时间轴，高亮当前轮次圆点（`.is-current`），对未知轮次使用空心虚化圆点（`.is-unknown`）。
9. **不同来源说法不一致（`.diffnote`，可选）**：按字段归并展示各媒体给出的冲突数值与原文链接。
10. **全部来源（`section#all-sources`）与入库查证来源**：统一采用同页去重后的规范化信源名称与四态时间格式（北京时间 + 美东原文日期 / 仅北京时间 / 仅美东原文日期 / 页面没写日期 · 读取日）。

## 5. 键盘交互、无障碍与安全文案红线

### 5.1 键盘快捷键与焦点管理

| 按键 | 触发上下文 | 行为说明 |
| :--- | :--- | :--- |
| `Tab` / `Shift+Tab` | 全局 / 筛选抽屉内 | 全局按视觉顺序聚焦并显示 `2px` `--c-focus` 轮廓；移动端抽屉打开时严格在抽屉内循环聚焦（Focus Trap） |
| `Escape` | 移动端筛选抽屉打开时 | 立即关闭抽屉、解除背景 `inert` 并将焦点归还至 `#open-filters` 按钮 |
| `j` / `k` | 列表视图（`#week`、`#list`、`#yc`）非输入态 | 在当前页面卡片主链接（`.co-card .co-link`）之间向下 / 向上移动焦点并滚动至视口 |
| `t` | 全局非输入态 | 快速在浅色与深色主题间切换并持久化 |

### 5.2 隐私、安全与外链守卫

1. **禁止搜索引擎收录与来源泄露**：`index.html` 固定声明 `<meta name="robots" content="noindex, nofollow">` 与 `<meta name="referrer" content="no-referrer">`。
2. **外链协议白名单**：`external()` 仅允许无用户名密码的 `http:` 与 `https:` URL 生成 `<a>` 标签，且一律附带 `target="_blank" rel="noopener nofollow"`；非法协议（如 `javascript:`、`data:`）自动降级为纯文本转义输出。
3. **零外部静态资源**：字体、图标、样式与脚本 100% 站内相对路径自包含，构建阶段由 `site._validate_outputs()` 强制扫描拦截任何绝对本地路径、占位域名、虚构样本名及禁用内部术语。
